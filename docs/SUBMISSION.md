# MoonReduce v0.1 本地评审材料

**工程结论：Ready for local v0.1 review。需求和采用证据仍有限，工程交付验收结论不代表月赛审核结果。** 未发布包、Release 或标签，未发送报名。

## 值得做：具体问题与选择理由

目标用户已有失败文件与识别同一问题的复现命令。人工删除时要保持输入有效、重复执行并确认问题未变；算法对拍还常需重算 n。MoonReduce 用单文件行删除、明确三态及输出实际复验闭合这段工作流。

当前已有 Picire、Lithium、C-Reduce 和 QuickCheck shrinking 等替代方案，不主张发明缩减算法。[任务比较](../examples/README.md)核对了一手文档：本项目已验证的增量是 MoonBit 类型直接接入，以及本工具公开且实测的预算、错误、最小性和复验证据契约；不能推断其他工具没有类似能力。公开索引也有同名 MoonReduce，功能差异未充分核验，选题独特性仍弱。

**需求证据：有限。** 有具体可重复流程，尚无真实用户访谈或生产缺陷材料。**差异化证据：工程增量可验证，市场优势与新颖性弱。采用证据：无外部试用，不能称已有采用。** 没有性能赛跑、接入成本对比或迁移意愿测量。

## 做得对：核心贡献与实际证据

- 纯 MoonBit 有序序列 ddmin：保留位置身份、三态、空候选、确定遍历、最终单删证明及安全提前停止；同步回调与请求／反馈接口均可复用。
- MoonBit Native 驱动负责 LF 字节段、参数数组进程、调用预算、保存、复验及 JSON／摘要。Python 负责示例适配与测试；没有调用另一个缩减器。
- 人工最大子段和缺陷：96 段／310 字节缩至 3 段／9 字节，98 次实际判断；正确值 33、错误值 19。独立逐删三次均无差异，并用连续区间枚举核对参考实现。
- 独立 MoonBit 账本模块直接复用 Entry、操作枚举和错误分类：8 个操作缩至 2 个，23 次核心回调；独立回放与全部单删通过。本地 workspace 依赖公开包，未复制核心或读取作者构建缓存。

Native Debug／Release 各 21 项、核心 Wasm 20 项以及真实 CLI 矩阵通过。外部计数验证预算；真实 PID／wait 证据验证超时、TERM 忽略与 Ctrl-C 清理；另覆盖 ENOSPC、报告／保存失败、32 MiB 双流输出、最终 NI/U/异常和最小性 U。实际 JSON 见 [报告实录](report.example.json)，完整方法和命令见 [STATUS](STATUS.md)。

## 做得完：交付范围与复现

已交付单文件、LF 字节保真、串行删除库与 CLI、README、完整案例、独立消费工程、测试、MIT 许可证与参考来源。干净 Git 源码配合重新下载的固定 SDK、空注册表完成全链路复现；发现并补齐首次 moon update 索引初始化步骤。固定 moon 0.1.20261012／moonc 0.10.15+943464bfa、async 0.22.4；归档哈希和安装命令在 [README](../README.md)。

支持范围仅为实测 WSL2 Ubuntu 26.04 Linux x86_64 Native。同机由实现者执行的干净复现不等于另一位用户或另一台机器试用。调用者负责格式有效性及同一问题签名；1-minimal 不是全局最短，U／预算中断不冒充证明，复验失败不成功。

不含 AST、多文件、格式自动修复、并行、沙箱、跨平台发行或随机故障稳定性保证。输入驻留内存、日志无磁盘配额，原子发布不承诺断电持久化；孤儿后代回收依赖实测 init/reaper，SIGKILL 不保证用户态清理。常见选定对拍流程已经闭合，必要的 n 重建由公开 oracle 承担；其他生产场景、外部采用和其他平台仍未验证。
